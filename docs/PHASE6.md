# Modern Farm - Phase 6 (Village, NPC, Dialogue, Friendship)
Kontrol: WASD jalan | E bicara dengan NPC (menghadap NPC), panen, tidur | W/S + E di dialog | 1-8 pilih item (untuk hadiah) | I inventory | ESC tutup dialog.

Farm -> Village: jalan lewat tepi barat Farm (jalan utama). Village -> Farm: tepi timur Village.
Tepi utara = Forest, tepi barat = Mine (masih toast, dibuat di Phase 10).
4 NPC: Mira (toko), Barnaby, Lila, Toby. Bicara +1 friendship (sekali sehari).
Hadiah: pilih item di hotbar (1-8), bicara, pilih "Beri hadiah". Disukai +10, tidak disukai -5, netral +2 (sekali sehari per NPC). Alat tidak bisa jadi hadiah.
NPC baru = tambah file .tres NpcData di res://data/npc/ (otomatis muncul di Village).
