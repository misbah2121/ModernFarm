# Modern Farm - Phase 4 (Waktu, Hari, Musim, Cuaca)
Kontrol: WASD jalan | 1-8 pilih | SPACE pakai alat | E panen / tidur (E di depan pintu rumah) | N tidur (debug).
Waktu: 1 menit game = 1 detik nyata (TimeManager.seconds_per_game_minute). Hari 06:00 - 02:00, lewat itu otomatis pingsan.
Musim 28 hari: Spring > Summer > Autumn > Winter. Tanaman hanya bisa ditanam di musimnya dan layu saat musim berganti.
Hujan/Storm: semua tanah olahan otomatis disiram pagi hari.
