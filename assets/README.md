# Aset

Aset grafis dan audio **tidak disertakan** di repo ini karena lisensinya tidak mengizinkan distribusi ulang.

| Folder | Isi | Sumber |
|---|---|---|
| `assets/modern_farm/` | Sprite, tileset, ikon, hewan, karakter | [Modern Farm oleh LimeZu](https://limezu.itch.io/) |
| `assets/fonts/` | `PixelGame.otf` | [Pixel Game Font](https://www.fontspace.com/pixel-game-font-f121080) |
| `assets/ui/`, `assets/audio/` | UI dan efek suara | Pack aset terpisah |
| `assets/shaders/` | Shader rumput bergoyang | ✅ Buatan sendiri (disertakan) |

Untuk menjalankan dari source code, unduh pack di atas lalu taruh sesuai struktur folder ini.
Kalau hanya ingin bermain, download versi siap main di halaman **Releases**.
